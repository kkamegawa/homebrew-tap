# Homebrew tap for Relaypublisher

This tap distributes `relaypublisher`, a CLI that publishes winget-like YAML manifests as Microsoft
Intune LOB apps, for macOS on Apple silicon.

The formula installs the self-contained `osx-arm64` single-file app attached to each GitHub release of
`kkamegawa/Relaypublisher`. Nothing is built here: the formula pins that archive by the sha256 recorded
in the release's `SHA256SUMS.txt`, and no .NET SDK is needed.

The Japanese translation is available in [README_ja.md](README_ja.md).

## Install

Homebrew 6.0 and later refuse to load a third-party tap until it is explicitly trusted, so add and
trust this tap once first:

```bash
brew tap kkamegawa/tap
brew trust --tap kkamegawa/tap
brew install relaypublisher
```

## Upgrade, pin, and uninstall

```bash
brew upgrade relaypublisher
brew pin relaypublisher
brew uninstall relaypublisher
```

## Supported platforms

- macOS on Apple silicon only. The formula refuses to install on an Intel Mac. On Intel Macs and on
  Linux, install the NuGet global tool with `dotnet tool install --global relaypublisher`.
- Stable releases only. Prereleases are published as NuGet packages only.
- The tap carries the latest version only. To roll back, use the NuGet global tool with `--version`.
- Do not install both the formula and the NuGet global tool; whichever comes first on `PATH` wins.

## How the formula is updated

When a stable Relaypublisher release is published, its release workflow opens a pull request here that
updates the version and sha256. The `brew test-bot` workflow installs the formula on an Apple silicon
runner, verifies the ad-hoc code signature with `codesign --verify --strict`, and runs
`relaypublisher --version`. The pull request is merged by hand after that check passes.

`Formula/relaypublisher.rb` is generated by `tools/New-HomebrewFormula.ps1` in the Relaypublisher
repository. Do not edit it by hand.
